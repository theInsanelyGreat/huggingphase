# huggingphase/readme-writer

Explores a project and drafts a complete README.md: overview, install, usage, configuration and license.

## Run it locally

```bash
npx github:theInsanelyGreat/huggingphase run huggingphase/readme-writer
```

## Inputs

- `write` (boolean) — Write README.md to disk

## What it can touch

- Tools: `fs.list`, `fs.read`, `fs.search`, `fs.write`
- Filesystem: read-write
